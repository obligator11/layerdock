## Why LayerDock?

PDFs are great for preserving how a document **looks**, but painful when you need to edit them.

Most PDF → Word converters either:

- Destroy the original layout
- Turn pages into images
- Require uploading your documents online

**LayerDock rebuilds the document instead.**

The goal:

> **Get your PDF back as a Word document you can actually edit.**

---

## Features

### ✏️ Editable Text

Text is reconstructed into editable Word content while preserving its position and formatting.

### 📊 Real Word Tables

Tables are rebuilt as actual editable Word tables — not screenshots.

### 🖼️ Images & Charts

Images and graphical elements are extracted and positioned according to the original PDF.

### 🔍 Built-in OCR

Convert scanned and image-only PDFs into selectable, editable text using local OCR.

### 📚 Batch Conversion

Queue multiple PDFs, convert them together, track progress, and get a completion summary.

### 🔒 100% Offline

Your documents stay on your computer.

**No uploads. No accounts. No cloud conversion.**

## Download

### Windows 10+

**[⬇️ Download the latest version](https://github.com/obligator11/layerdock/releases/latest)**

The installer includes everything LayerDock needs. No separate dependencies or OCR installation required.

1. Download the installer
2. Install LayerDock
3. Drag in a PDF
4. Click **Convert**
5. Open your generated `.docx`

That's it.

## Feedback

PDFs are complicated, and some documents will contain edge cases.

If you find a PDF that doesn't convert correctly, please [open an issue](https://github.com/obligator11/layerdock/issues) and tell us:

- What type of PDF it was
- What went wrong
- What you expected
- Screenshots if possible

Real-world PDFs help make LayerDock better.
